LaterClip

두 기기, 하나의 영상 보관함.

이 웹사이트는 화면만 제공합니다. 영상 목록은 본인의 비공개 Google Sheets에 저장되고, 개인 Apps Script가 저장·읽기·수정을 처리합니다.

최초 설정이 완료되기 전에는 실제 영상을 저장할 수 없습니다. 개인 연결 키는 저장소나 공개 웹페이지에 올리지 않습니다.

1. 저장소 연결

  1. 본인 Google Sheets의 Extensions > Apps Script에서 이 프로젝트의 backend/Code.gs와 backend/Bridge.html을 추가합니다. HTML 파일 이름은 Bridge로 지정합니다.
  2. initializeLaterClip 함수를 한 번 실행합니다. 기존 저장 행은 지우지 않습니다.
  3. Project Settings > Script properties에서 WEB_ORIGIN을 이 웹사이트의 출처로 지정합니다. https://사용자이름.github.io 형태이며 저장소 경로는 포함하지 않습니다.
  4. Deploy > New deployment > Web app에서 본인 계정으로 실행하도록 배포합니다. 공유 단축어가 Google 로그인 창 없이 호출할 수 있는 접근 설정이 필요하며, 모든 데이터 요청은 코드에서 개인 키를 검사합니다. 시트 자체는 비공개로 유지합니다.
  5. 발급된 /exec 주소와 API_TOKEN을 이 웹사이트의 내 보관함 연결에 입력합니다.

2. iPhone과 Mac의 공유 단축어

두 기기에 Shortcuts를 준비하고, 공유받은 URL을 해당 Apps Script 주소에 보내는 ‘LaterClip에 저장’ 단축어를 만듭니다. Mac의 요청은 device: Mac, iPhone의 요청은 device: iPhone으로 구성합니다.

Safari의 Share에서 실행하려면 단축어의 Show in Share Sheet를 켜고 링크 입력을 받도록 설정합니다. 단축어는 웹사이트를 여는 것만으로 자동 설치되지 않습니다.

3. 다시 보기

iPhone과 Mac에서 같은 웹주소에 접속해 각각 보관함을 연결합니다. iPhone에서는 Safari의 Add to Home Screen으로 아이콘을 추가할 수 있습니다. 웹앱은 앱 실행 중 약 60초마다 목록을 갱신하며 수동 새로고침도 가능합니다.

분류와 연결에 관하여

첫 버전은 영상 제목의 키워드로 분류합니다. AI가 영상을 분석하지는 않습니다. 제목을 가져올 수 없어도 링크는 미분류로 보존합니다. 연결 키를 잃어버리거나 노출하면 Apps Script에서 교체하고 두 기기의 연결도 갱신해 주세요.
